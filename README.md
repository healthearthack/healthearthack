This profile is not a static portfolio—it is an **automated cyber-physical research engine** that runs every 6 hours via GitHub Actions:

 **1. 📥 PROCURE (Raw Earth & Satellites):** Pulls live atmospheric barometrics from NOAA (`weather.gov`), carbon sounders from NASA OCO-2, and downhole pressure from deep Smackover wellbores.
